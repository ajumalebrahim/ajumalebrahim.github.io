# Ajumal Ebrahim — Portfolio

A responsive personal portfolio for GitHub Pages. Built with HTML, CSS, and JavaScript; no build step or package installation required.

## Publish on GitHub Pages

1. Create a public repository named `ajumalebrahim.github.io` in the `ajumalebrahim` account. If that repository already exists, review its content before adding or replacing files.
2. Upload the contents of this folder to the root of the repository. `index.html` must be at the root, not inside an extra folder.
3. In **Settings → Pages → Build and deployment**, choose **Deploy from a branch**.
4. Choose the `main` branch and `/(root)`, then save.
5. Once GitHub completes deployment, the site will be available at `https://ajumalebrahim.github.io/`.

GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Edit your portfolio

- Content and links: `index.html`
- Colours, typography, and responsive layout: `styles.css`
- Mobile navigation: `script.js`
- Photo, CV, and app images: `assets/`

All local paths are relative, so the site also works under a GitHub Pages project path.
